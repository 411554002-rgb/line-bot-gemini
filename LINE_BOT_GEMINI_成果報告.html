📋 一、專案概述

本次專案目標是建立一個能讓使用者在 LINE 聊天室中與 Google Gemini AI 對話的智慧機器人，整個過程從構想、程式開發、金鑰申請、除錯，到最終成功上線，全程在單次對話中完成。

🗺️ 二、開發歷程時間軸

  • 1

    需求確認與技術選型

    確定以 Python 3.13 + FastAPI + LINE SDK v3 + google-genai SDK 作為技術棧，並規劃完整目錄結構。

  • 2

    程式碼撰寫與套件安裝

    建立 main.py（Webhook 伺服器）、gemini_service.py（AI 模組）、.env（金鑰設定）等核心檔案，並自動安裝所有依賴套件。

  • 3

    LINE Developers 頻道建立

    使用者原先建立的是「LINE MINI App」頻道（不支援 Messaging API），後依指引重新建立正確的「Messaging API」頻道。

  • 4

    金鑰配置

    成功取得並填入 LINE Channel Secret、LINE Channel Access Token、Google Gemini API Key，三組金鑰全數就位。

  • 5

    ngrok 穿透設定

    完成 ngrok 安裝、帳號註冊、AuthToken 配置，成功取得 HTTPS 公開網址並設定至 LINE Webhook URL。

  • 6

    模型名稱除錯與修正

    解決 Gemini 模型名稱版本過時問題，最終確認使用 gemini-3.8-flash 作為主模型、gemini-3.5-flash-lite 作為備援模型。

  • 7

    🎉 成功上線！

    LINE Bot 成功串接 Google Gemini，使用者在 LINE 傳送訊息後機器人正確回覆 AI 生成內容。

🔧 四、遭遇問題與解決方案

問題 解決方案 狀態

📁 五、產出檔案清單

main.py

FastAPI 主程式與 LINE Webhook 進入點。包含簽章驗證、訊息分發、Reply API 回覆與長文字分割邏輯。

gemini_service.py

Gemini API 呼叫封裝模組。支援多輪對話記憶（Sliding Window）、自動降級備援模型與 /reset 清除指令。

.env

環境變數設定檔。儲存 LINE Channel Secret、Access Token 與 Gemini API Key，不進入版本控制。

requirements.txt

專案依賴清單：fastapi, uvicorn, line-bot-sdk, google-genai, python-dotenv 等共 30+ 套件。

README.md

快速啟動指南：含金鑰取得流程、ngrok 設定步驟與 LINE Webhook 配置說明。

LINE_BOT_GEMINI_專案計畫書.html

可直接用瀏覽器開啟的視覺化計畫書，含架構圖、技術規格表，右下角附列印/PDF按鈕。
