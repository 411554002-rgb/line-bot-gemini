🔍 一、版本改善核心紀錄（四件事完整對照）

依據專題成果改善規範，以下詳實記錄「原本的問題」、「修改內容」、「前後差異」與「重新測試結果」：

STEP 1. 原本的問題

第一版（v1.0）存在的缺陷與痛點

  • 模型資訊缺乏時空認知與繁中引導：原本程式碼未設定 System Instruction，Gemini 會以簡體中文或預設冷淡風格回應，且受限於 2025 訓練邊界而無法給予妥善的引導說明。
  • 無任何快捷指令與自訂人設：使用者無法切換助理風格（如家教、導師），且只能被動打字，缺乏指令列表。
  • AI 生成延遲期間無狀態回饋：Gemini API 處理較長文本需花費 2~4 秒，期間 LINE 聊天室一片空白，使用者誤以為機器人當機或斷線。
  • 無快捷引導按鈕（Quick Reply）：重設對話需使用者自行手動輸入文字，新加入好友時亦無任何功能迎賓介紹。
STEP 2. 修改內容

AI Agent 執行的具體修改與優化

  • 升級 System Instruction 提示工程 (gemini_service.py)： 加入專屬繁體中文提示詞框架，嚴格規範在地用語、親切語氣、結構化條列排版與時間邊界引導。
  • 新增 4 大指令系統與自訂人設： 支援 /help（使用說明選單）、/role <角色設定>（即時切換人設）、/status（連線狀態與模型查詢）、/reset（清空對話記憶）。
  • 串接 LINE 原生載入中動畫 (main.py)： 使用 ShowLoadingAnimationRequest，在呼叫 Gemini 期間於聊天室觸發官方「輸入中...」載入動畫。
  • 實作 Quick Reply 底部快捷選單與 FollowEvent 迎賓訊息： 每則回覆訊息底部附帶「重設對話」、「使用說明」、「系統狀態」、「自我介紹」快捷按鈕；新用戶加好友時主動發送導覽。
STEP 3. 前後差異

第一版 (v1.0) 與改善版 (v2.0) 核心差異比較

比較項目 第一版 (v1.0 - Commit 31379d5) 改善版 (v2.0 - 最新版本)
輸入提示與風格引導 無提示詞，回答風格飄忽，可能出現簡體字或死板回應 專屬繁體中文 Prompt 架構，格式清晰易讀且具備時間認知
動態人設功能 無任何角色切換能力 支援 /role 指令，可自由切換英文老師、程式導師等角色
等待體驗 (UX) 等待 2~4 秒期間介面完全靜止，易造成重送訊息 原生輸入中載入動畫 (Loading Animation)，等待感大幅降低
操作便捷度 純文字手打，無選單引導 Quick Reply 底部快捷按鈕，一鍵點擊重設或呼叫說明
新用戶指引 加好友無反應，使用者不知如何開始 FollowEvent 迎賓訊息，自動列出支援功能與操作範例
STEP 4. 重新測試結果

程式碼編譯、模組整合與端到端實測結果

  • Python 語法與編譯測試：main.py 與 gemini_service.py 經 py_compile 測試通過，零語法錯誤。
  • 指令響應測試：/help 正確返回 233 字完整功能選單；/status 正確輸出模型版本與運行狀態；/reset 正確重置記憶。
  • 自訂人設 (/role) 測試：成功切換為「精通 Python 的技術導師」角色，隨後提問 API 概念即以精準生動的比喻回應。
  • LINE SDK 介面相容測試：ShowLoadingAnimationRequest 與 QuickReply 模組正確初始化，成功相容 LINE Messaging API v3。
