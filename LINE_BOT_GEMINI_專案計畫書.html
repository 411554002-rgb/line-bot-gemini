摘要 (Executive Summary)

本專案旨在建置一套高效能、高擴展性之 LINE 官方帳號（LINE Official Account）智慧對話助理。透過整合最新版 Google Gemini 大型語言模型（LLM），賦予機器人自然語言理解、邏輯推論、多輪對話記憶與長篇資訊彙整能力。使用者無需額外安裝專屬 App，即可在日常最熟悉的 LINE 通訊軟體中，享受全天候即時的 AI 智慧服務。

一、 專案背景與目標 (Project Background & Objectives)

1.1 現況痛點

  • 傳統 LINE 機器人僵硬：大部分基於關鍵字比對或固定問答樹（FAQ Tree），無法理解使用者自然的語意表達與上下文關聯。
  • 維護成本高昂：關鍵字規則需人工持續擴充與微調，面對生僻問答容易陷入「我不懂您的意思」的窘境。
  • 跨平台使用門檻：雖然市面上已有網頁版 AI 工具，但非技術使用者在切換網頁或登入驗證時仍有使用障礙。

1.2 專案預期目標

  1. 即時語意理解：利用 Gemini 先進模型，精確辨識使用者意圖並給予高質量解答。
  2. 上下文多輪記憶：具備短期對話記憶能力，能連貫上下文進行追問與深入討論。
  3. 無縫整合體驗：直接嵌入 LINE 生態圈，支援群組與個人一對一聊天。
  4. 低延遲與高彈性：採用非同步（Asynchronous）後端架構，確保 Webhook 快速回應，避免 LINE 逾時重發。

    Server->>Server: 檢查字數長度 (若 >4800 字則進行智慧分段)
    Server->>LINE: MessagingApi.reply_message(reply_token, 格式化訊息)
    LINE-->>User: 於 LINE 聊天室中渲染 AI 回覆內容

三、 技術規格評估 (Technical Stack Evaluation)

元件層級 選用技術 選用評估與效益
後端語言 Python 3.13 生態系成熟，具備最強大的 AI/LLM SDK 官方原生支援。
Web 框架 FastAPI + Uvicorn 非同步 ASGI 框架，單機並發效能卓越，開銷極低。
通訊協定 SDK LINE Messaging API SDK v3 LINE 官方最新版 Python SDK，具備完整簽章校驗與型別保障。
AI 核心引擎 Google GenAI SDK (google-genai) Google 官方統一版 SDK，支援 Gemini 2.5/1.5 系列，百萬 Token 上下文與秒級回應。
環境配置 python-dotenv 遵循 12-Factor App 原則，機敏金鑰與程式碼嚴格隔離。
通道測試 ngrok / localtunnel 快速將本機服務映射為合法的 HTTPS 公開端點供 LINE 測試。

四、 核心功能規格 (Functional Specifications)

  • 全領域智慧問答：程式輔助、公文與文案擬稿、語言翻譯、生活諮詢與邏輯推理。
  • 多輪對話記憶（Sliding Window）：維護最近 10~12 次上下文，對話不斷層；輸入 /reset 可隨時清空記憶。
  • 超長文字防護：針對 LINE 單則 5,000 字上限，內建智慧分割器（每 4,800 字拆分一則，最多發送 5 則）。
  • 容錯降級機制（Fallback）：主模型若遇瞬時配額異常，自動降級調用 gemini-1.5-flash，確保服務不中斷。

五、 資安與維運成本 (Security & Operations)

資安規範

1. 全鏈路 HTTPS：強制加密傳輸，防止中間人竊聽。
2. HMAC-SHA256 簽章驗證：阻擋非 LINE 官方之惡意仿冒偽造請求。
3. 金鑰隔離：Token 與 API Key 僅留存於 .env，不提交版控。

六、 未來進階擴充願景 (Future Enhancements)

  1. 多模態圖像辨識：支援使用者傳送照片/發票，由 Gemini 辨識內容並提取數據。
